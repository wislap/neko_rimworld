# v3.3 运行默认与能力边界

当前源码版本为3.3.0，包发布、安装部署和真实游戏验收分别记录。版本号不表示七日机制或经营质量已经通过。

## 正常使用

- 插件不自动启动，自动游玩也不随插件启动或重启恢复。普通咨询默认只读。
- 自动游玩须在面板显式启用；前台处理用户意图、接管与沟通，唯一规划者串行提交配置修改。
- 开局需要配置时申请规划者暂停；原有用户、未知或强制暂停保持归属。恢复要求当前原生证据、授权和expected_owner守卫。
- 支持工作优先级、医疗方针、允许区域、禁止标记、账单字段、研究、储存优先级、物品过滤和添加生产账单九类配置。没有直接喂食、营救、战斗或建造工具。
- 不改变玩家storyteller、敌人、资源或游戏速度。研究场景的清场、补给、命名和Ultrafast不属于产品启用流程。

## 模型与额度

模型地址、型号和密钥由用户配置，没有默认提供商。现有默认保持：单次900秒、最多60次请求、累计输入估算200万tokens、每次输出上限32768；网络请求60秒，连接10秒、首响应45秒、流空闲20秒，收尾预留15秒。这些是上限，不是保证消耗量。

自动游玩规划运行再取请求上限的较小值：startup60、daily40、signal20、escalated20。共享殖民地累计额度默认100000次请求、1000000000输入tokens；可设置价格和费用限额。未知usage保留预约，未定价不显示为零账单。设置在下一次显式启用时应用，不静默覆盖已有用户值。

上述数值在plugin.toml、config.example.toml和运行时设置中一致。研究用单次2000万输入、12000次/8亿累计批准额度不成为产品默认。S7使用这些研究额度，没有验证同一轨迹在200万产品默认下可以完成；最终正式包仍需在产品默认下做实际验收。

## 节奏与输入

普通JSON按需裁剪是唯一生产路径。局势背景最多1000tokens，同连接、殖民地和加载身份下复用30000游戏ticks；原始观察和采样时间保留。

注意力由原生事实和有期限的声明推导为steady/focus/urgent。日复核从启用tick按60000ticks固定到期，逐次记录身份，忙碌时合并待执行工作，终点不补跑。关注/紧急提档复核分别15000/2500ticks，完整策略见workspace/attention_policy.v1.json。运行类型和注意力等级共用一套实现，不是用户选择的实验方案。

加载身份由首次确认的colony.observed、colony.load、autoplay.activation和原生game.event确定；前台、进度和旧运行结果不改变当前加载身份。普通咨询首次连接也记录确认身份，不把空历史标成一次读档；旧库历史没有确认身份时沿现有load复核提示处理。旧结果保留原scope和context_tick，完成记账使用原scope水位，不能从旧scope派生新工作。较早存档的tick不与旧scope比较大小。

## 正式启动与研究启动

正常Mod启动预热五类行为读取元数据，定义发布每帧协作预算2ms/8条。只有明确的私有研究启动声明可缩减必需元数据、复用校验后的离线定义generation，并使用12ms/128条发布预算。实际行为读取仍检查游戏二进制、依赖和实时补丁。

bench的EndurancePlugin、故障注入、受控policy恢复、fixture和隔离控制器只用于研究。普通插件不会自动恢复端点故障后的policy暂停；用户须显式停用/启用，游戏恢复仍受原生保护。研究启动耗时、脚本九写覆盖和S7存活快照各有范围，不能替代正式包、普通SDK/面板和经营内容评价。

Mod运行时版本统一由`BridgeRuntime.ModVersion`定义为3.3.0，Mod配置和握手沿用该值；打包同时核对运行时、程序集和About元数据。协议标识保持各自版本。机制索引的离线构建属于工作区脚本，正式插件只读取已准备且二进制身份匹配的generation。
